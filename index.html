    AI 채점 설정

    claude.ai 밖(휴대폰 홈 화면, GitHub Pages)에서 열었을 때 AI 채점을 쓰려면 Anthropic API 키를 넣어 주세요. 키는 이 기기의 브라우저에만 저장되고 Anthropic 서버로만 전송됩니다. 공용 기기에서는 넣지 마세요.

    읽기 음성

    음성 품질은 기기에 설치된 음성에 따라 다릅니다. iPhone/iPad: 설정 → 손쉬운 사용 → 콘텐츠 말하기 → 음성 → 일본어에서 「Kyoko (고품질)」 또는 「O-Ren (프리미엄)」을 내려받으세요. Mac: 시스템 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 시스템 음성 → 관리에서 같은 음성을 내려받을 수 있습니다. Windows/Android: Edge 브라우저의 「Microsoft Nanami Online (Natural)」, Chrome의 「Google 日本語」가 자연스럽습니다.
